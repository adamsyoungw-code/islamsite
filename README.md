# منهج العلم — Уроки по исламским наукам

Статический сайт-каталог уроков по исламским наукам (тафсир, хадис, фикх,
акыда, арабский язык и др.). Уроки на арабском и русском языках,
с поиском, фильтром по языку и навигацией по разделам. Поддержка RTL.

## Структура

- `index.html` — разметка страницы
- `styles.css` — оформление (тёмная тема, RTL)
- `app.js` — загрузка данных, поиск, фильтры, рендеринг
- `data.json` — все уроки по разделам (источник данных)

## Как запустить локально

Сайт грузит `data.json` через `fetch`, поэтому его нужно открывать
через локальный сервер (не как `file://`):

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Как добавить ссылки на уроки

В `data.json` у каждого урока есть `title`, `teacher`, `lang`.
Чтобы добавить ссылку, допишите поле `url`:

```json
{ "title": "تفسير الجلالين", "teacher": "لبيب نجيب", "lang": "ar", "url": "https://t.me/channel/345" }
```

Сайт сам определяет тип ссылки и показывает нужную кнопку:

- `youtube.com` / `youtu.be` → «Смотреть на YouTube» (или «Плейлист на YouTube»)
- `t.me` / `telegram` → «Открыть в Telegram»
- любая другая (PDF и т.п.) → «Открыть урок»
- без `url` → бейдж «скоро»

В заголовке раздела показывается «доступно ссылок / всего уроков».

## Отдельные уроки внутри курса (Урок 1, Урок 2 …)

Чтобы по клику на курс открывался список отдельных уроков, добавьте
массив `episodes`. Клик по карточке откроет панель со всеми уроками,
каждый — со своей ссылкой:

```json
{
  "title": "تفسير النسفي",
  "teacher": "علي هاني العقرباوي",
  "lang": "ar",
  "url": "https://www.youtube.com/playlist?list=PLSfhlQ01CKZytmtPf_6ADhYzDE41HxdCZ",
  "episodes": [
    { "title": "Урок 1. Вступление", "url": "https://youtu.be/VIDEO_ID_1" },
    { "title": "Урок 2. Сура аль-Фатиха", "url": "https://youtu.be/VIDEO_ID_2" },
    { "title": "Урок 3", "url": "https://t.me/channel/57" }
  ]
}
```

Правила:
- `url` (плейлист целиком) — необязателен; если есть, в панели будет
  кнопка «Весь плейлист».
- `episodes` — список уроков. У каждого `title` (если не указать —
  будет «Урок N») и `url`. Урок без `url` показывается как «скоро».
- Ссылки в `episodes` тоже распознаются автоматически
  (YouTube / Telegram / прочее).

## Разделы

16 разделов, 494 урока. Новые уроки добавляются в массив `lessons`
соответствующего раздела в `data.json`.
