# Исламские знания

Сайт-каталог уроков по исламским наукам. Интерфейс на русском,
простой и строгий стиль.

## Структура сайта

- **Разделы**: Акыда, Фикх, Тафсир, Хадис, Адаб (легко добавить новые).
- В разделе — **циклы** (Цикл 1, Цикл 2 …) с указанием уровня.
- В цикле — **уроки** (Урок 1, Урок 2 …).
- В уроке — **аудио урока**, **текст урока** и **тесты** для проверки знаний.
- Отдельный раздел **Библиотека** — книги в электронном виде.
- **Регистрация / вход**: через Google, Apple или почту с паролем.

## Файлы проекта

- `index.html` — каркас страницы
- `styles.css` — оформление (светлая, строгая тема)
- `app.js` — роутинг (по `#`), рендеринг разделов, уроков, тестов, библиотеки
- `auth.js` — авторизация (прототип на `localStorage`)
- `data.json` — все данные (разделы, циклы, уроки, библиотека)

## Запуск локально

`data.json` загружается через `fetch`, поэтому сайт нужно открывать
через локальный сервер, а не как `file://`:

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Как добавить контент

### Новый раздел
Добавьте объект в массив `sections` в `data.json`:

```json
{ "id": "novyy", "title": "Название", "description": "…", "cycles": [] }
```

### Цикл и уроки
Внутри раздела в `cycles`:

```json
{
  "id": "akyda-1",
  "title": "Цикл 1. Введение в акыду",
  "level": "Базовый уровень",
  "lessons": [
    {
      "id": "akyda-1-1",
      "title": "Урок 1. Что такое акыда",
      "audio": "https://example.com/lesson1.mp3",
      "text": "Текст урока…",
      "tests": [
        { "question": "Вопрос?", "options": ["A", "B", "C"], "correct": 1 }
      ]
    }
  ]
}
```

- `audio` — путь к mp3. Можно хранить файлы прямо в репозитории в папке
  `audio/` и указывать относительный путь, например `audio/akyda-1-1.mp3`
  (см. `audio/README.md`). Пусто — покажется «будет добавлено позже».
- `text` — текст урока (переносы строк сохраняются).
- `tests` — массив вопросов; `correct` — индекс правильного варианта (с 0).

### Библиотека
Добавьте книгу в массив `library`:

```json
{ "title": "Название", "author": "Автор", "description": "…", "url": "https://…" }
```

## Авторизация

Текущая реализация — **клиентский прототип** на `localStorage`:
вход по почте/паролю работает локально, кнопки Google и Apple
запрашивают почту в демо-режиме.

Для реального входа нужен бэкенд или сервис аутентификации
(например, Firebase Auth или Supabase) с настоящими OAuth client ID
и серверной проверкой. Логика входа вынесена в `auth.js` — реальные
провайдеры подключаются там.
