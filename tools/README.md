# Агент: скачивание аудио из Telegram-канала

`telegram_audio_downloader.py` подключается к Telegram через ваш аккаунт
и скачивает все аудиозаписи из указанного канала, сохраняя файлы **с их
названиями**. Для каждого файла пишется `manifest.json` с метаданными.

## 1. Получите доступ к API

1. Зайдите на https://my.telegram.org → **API development tools**.
2. Создайте приложение и скопируйте `api_id` и `api_hash`.

## 2. Установите зависимости

```bash
pip install -r tools/requirements.txt
```

## 3. Запустите

```bash
export TG_API_ID=123456
export TG_API_HASH=ваш_api_hash

python tools/telegram_audio_downloader.py --channel @nazvanie_kanala
```

При первом запуске Telethon попросит номер телефона и код из Telegram
(сессия сохранится в файл `tg_audio_session.session`, повторно вводить не
нужно).

### Параметры

| Параметр      | Описание                                              |
|---------------|-------------------------------------------------------|
| `--channel`   | `@username`, ссылка `t.me/...` или числовой id канала |
| `--out`       | папка для сохранения (по умолчанию `audio/`)          |
| `--limit`     | сколько последних сообщений просмотреть (`0` = все)   |
| `--api-id`    | `api_id` (если не задан `TG_API_ID`)                  |
| `--api-hash`  | `api_hash` (если не задан `TG_API_HASH`)              |

## Что получится

- В папке `--out` появятся файлы вида `Название трека.mp3`
  (для треков с метаданными — `Исполнитель - Название.mp3`).
- `manifest.json` — список скачанного: название, файл, исполнитель,
  длительность, дата, ссылка на сообщение.
- Повторный запуск **догружает только новое** (по `message_id`),
  уже скачанное пропускается.

## Связь с сайтом

Названия из `manifest.json` удобно использовать как заголовки уроков, а
имена файлов — подставлять в поле `audio` в `data.json`. Помните про лимит
GitHub 100 МБ на файл — большие записи лучше класть в GitHub Releases
(см. `audio/README.md`).

## Важно

- Скачивайте только тот контент, на который у вас есть права.
- Файл сессии `tg_audio_session.session` — это доступ к вашему аккаунту,
  **не коммитьте его** (он уже добавлен в `.gitignore`).
