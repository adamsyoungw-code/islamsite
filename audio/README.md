# Аудио уроков

Сюда кладите mp3-файлы уроков. Затем в `data.json` у нужного урока
укажите относительный путь в поле `audio`:

```json
{
  "id": "akyda-1-1",
  "title": "Урок 1. Что такое акыда",
  "audio": "audio/akyda-1-1.mp3",
  "text": "...",
  "tests": []
}
```

## Рекомендации

- Формат: **mp3**, битрейт ~**64 кбит/с** для речи (чисто и компактно:
  примерно 30 МБ за час).
- Имя файла — латиницей, удобно по схеме `<раздел>-<цикл>-<урок>.mp3`,
  например `akyda-1-1.mp3`.
- Лимит GitHub: один файл — до 100 МБ.

## Если файлов много (десятки часов)

Загружайте mp3 в **GitHub Releases** (до 2 ГБ на файл) и в `data.json`
указывайте полную ссылку:

```json
"audio": "https://github.com/adamsyoungw-code/islamsite/releases/download/audio/akyda-1-1.mp3"
```
